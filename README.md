# Personal Portfolio Website

A responsive personal portfolio website built with HTML and CSS. The page presents a developer profile with an introduction, skills, resume summary, and contact section.

## Features

- Hero section with profile image and call-to-action buttons
- About Me section with personal information
- Skills section featuring JavaScript, React, Node.js, and MongoDB
- Education and professional experience summary
- Social media links
- Contact message form layout
- Font Awesome icons and Google Fonts integration

## Technologies Used

- HTML5
- CSS3
- Google Fonts: Open Sans
- Font Awesome

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` directly in a browser.

For a better development experience, use the VS Code **Live Server** extension and select **Open with Live Server** from `index.html`.

## Customization

- Update profile text, skills, education, and experience in `index.html`.
- Replace images inside `images/` with your own assets.
- Change colors, spacing, typography, and responsive styles in `styles/Portfolio.css`.
- Replace the empty social links and contact actions with real URLs or backend endpoints.

## Note

This is a frontend-only project. The contact form is currently a visual layout and does not submit messages to a server.
